# LoLSim 작업 현황 (메인 세션)

`orch` = `python -X utf8 $HOME/.claude/hooks/lolsim_orch.py`

1. `orch board --full`을 실행하고 결과를 그대로 보여 준다(세션 링크 `[Txx 제목](#local_…)` 유지).
   - 작업 하나를 자세히 볼 때는 `orch show Txx`(브랜치, 커밋, 데모 경로, 패치노트 초안, 시각)를 쓴다.
2. 이상 신호를 점검하고, 있으면 현황판 아래에 한 줄씩 덧붙인다.
   - **멈춤 N분**: 상태는 작업 중인데 그 세션의 턴이 끝난 채 멈춰 있다. `list_sessions`/`get_session`으로 확인한다. 질문을 남기고 멈췄으면 사용자에게 전하고, 그냥 멈췄으면 `SendMessage`로 이어서 하라고 한다.
   - **결정 필요**(`blocked`): 그 질문을 사용자에게 그대로 묻는다.
   - **세션이 없어짐**: 레지스트리에는 진행 중인데 세션이 아카이브·삭제됐으면 사용자에게 알리고, 다시 맡길지 묻는다.
   - **컨펌 대기가 오래됨**: 데모 경로와 함께 컨펌을 다시 요청한다.
3. 경과시간 기준:
   - 진행 중: 시작부터 지금까지
   - 컨펌 대기: 작업에 걸린 시간 + 대기 시간
   - 완료: 시작부터 배포까지
